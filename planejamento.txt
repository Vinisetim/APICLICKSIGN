Desenvolvimento de script para conectar api clicksign v1 - testes

2. Documento (Converter arquivo do documento para base64 e adicionar ao envelope) [feito]

3.Adicionar Signatários (criar signatário) [Feito]

4. Adicionar Requisitos (adicionar critérios para validação da assinatura - qualificação do documento, autenticação por email ou telefone) [Feito]

5.*opcional* adicionar observadores (entidades que não precisam participar do processo de assinatura mas podem ser notificadas do progresso) [Opcional]

6. Notificar (notificar o signatário de que existe um documento para ele assinar) []

7. Conclusão do teste (começar a planejar a implementação real da ferramenta para assinatura de múltiplas multas e como deve ser configurada cada etapa)
